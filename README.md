# Figma Assignment

A responsive landing page built using React, Vite, and Tailwind CSS based on the provided Figma design.

## Features

* Responsive design for desktop and mobile
* Modern UI implementation
* Custom SVG decorative curves
* Reusable React components
* Tailwind CSS styling

## Tech Stack

* React
* Vite
* Tailwind CSS

## Live Demo

https://figma-assignment-ecru.vercel.app

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
